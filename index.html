A ROS 2 workspace for the manipulator I work on in the MaRS club. It holds the arm's description, a MoveIt 2 motion-planning setup, a Gazebo simulation, and small tools for sending goals to the arm.

1. My work in short

This repository gathers everything I have done on manipulators. The main workspace, ws_manip_club, is built around a five-joint arm with a two-jaw gripper (base rotation, two pitch joints, and a wrist that pitches and rolls). It contains:

  • Robot description (gen5manipulator1): the arm's URDF and meshes, a launch file to view it, and its joint names.
  • MoveIt 2 configuration (moveit_pkg2): generated with the MoveIt Setup Assistant and tuned by hand. It uses the OMPL planners, the Pilz Cartesian limits and the pick_ik inverse-kinematics solver, with a body group for the arm and an eef group for the gripper.
  • Simulation: launch files that bring the arm up in Ignition Gazebo with ros2_control, and a second launch file that starts MoveIt, so planned motions run on the simulated arm.
  • Control tools: two scripts that send an exact target pose to MoveIt's move_group through its action interface, and a small slider window that moves each joint directly by publishing joint trajectories.

To get IK-based planning and execution working, I also modified a parameter in MoveIt 2's own source code, in the file kinematics_base.h.

4. Running it

Tested with Ubuntu 22.04, ROS 2 Humble, MoveIt 2 and Ignition Fortress. From the workspace folder, install the dependencies and build, then start the simulation and MoveIt in two terminals:

cd ws_manip_club
rosdep install --from-paths src --ignore-src -r -y
colcon build
source install/setup.bash

# terminal 1: Ignition Gazebo simulation
ros2 launch moveit_pkg2 ignition_sim.launch.py

# terminal 2: MoveIt 2 with RViz
ros2 launch moveit_pkg2 moveit.launch.py

With both running, send a goal with python3 src/target_pose1.py, or move the joints by hand with python3 src/gui_sliders_jointControl.py.
